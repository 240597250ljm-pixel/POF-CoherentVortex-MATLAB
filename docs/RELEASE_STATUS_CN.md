# POF MATLAB v1.0-rc3 发布说明

## 本次已修订

- 保留和使用经过两日原始VEC头核实的单位边界：0604 m/s保持原值，0605 pixel位移乘 114.910004/50 = 2.29820008（实验人员确认标定相同）。
- 核心方法写成独立`+pof/`函数：2D Liutex、正Liutex P80、4单元核心与2单元边缘排除、Gaussian粗粒化水平二分量Π、14个间距区间的S3、有限窗口Voronoi、CSR/SSI统计参考、涡旋近场/负值贡献分解、SI S4 的R90富集、2D梯度和应变匹配、10帧循环移动块Bootstrap。
- 使用与历史源码相同的 **inclusive** 百分位线性插值，而不是受MATLAB版本影响的默认`prctile`算法。
- 旧生产程序不进入可执行入口，仅保留3份引用源码，全部历史程序另行归档。
- 中英文README、24项图表覆盖说明、GitHub文件完整性CI、论文参数表、运行示例。

## 不得夸大的部分

新函数实现论文**方法定义**并有待MATLAB执行的合成检验；没有对2935帧/81773目录完成一键完整复现，也没有证明所有终稿图/表逐点一致。历史WP4/5/C9/C10含**额外0.8网格速度预平滑**，当前论文仅明确涡旋识别的Liutex场0.8网格平滑和滤波宽度ℓ；额外速度预平滑尚须与最终图件生产记录做来源对齐。SI S6/S7的旧81775目录与主文81773目录亦未自动合并或改写。旧脚本不会被当成当前默认计算程序。

本包为**公开GitHub仓库的科研方法参考源码候选版**；目前尚未选择开放源码许可证，因此对外使用、修改及再分发权利需要另行取得授权。源码公开不等于完全图件复现认证。
